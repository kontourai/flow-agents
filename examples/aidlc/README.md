# AI-DLC Kit

The AI-DLC methodology, profile flows, lifecycle implementation and conformance tests are maintained in [kontourai/aidlc-kit](https://github.com/kontourai/aidlc-kit).

Flow Agents provides the public installed-kit execution, Docker/Codex host adapter, scoped provider broker and storage-admission contracts. Install and run AI-DLC using the standalone kit's documented public entry; this engine repository carries no independent methodology copy.
