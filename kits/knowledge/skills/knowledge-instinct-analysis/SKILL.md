# Instinct analysis

Use Knowledge consolidation to plan confidence changes for reviewed compiled claims and their reviewed, linked observations. An additional distinct source adds 0.05; each complete inactive week subtracts 0.02. Confidence stays between 0 and 1. A score below 0.2 yields a retirement recommendation, not a deletion.

Provide the existing source boundaries and a verified baseline time. The returned plan requires review; consolidation does not apply the confidence change. Do not disable a scheduled job or alter a legacy store from this skill.
