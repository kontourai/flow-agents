# Observe

Keep the existing capture behavior and timing. Give the dream host the authorized observation source and a stable opaque source ID. The run stages each scrubbed tool event as a raw proposal and routes any extracted claim for review. It saves the source cursor only after the batch's effects finish.

Do not treat a tool result as a human statement. Do not print observation contents in a report. A source that is malformed or changes under its saved cursor must be reconciled before retrying.
